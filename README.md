# Interactive E-commerce Website

A modern interactive e-commerce website built using PHP, MySQL, HTML, CSS, and JavaScript.

## Features
- User Registration & Login
- Product Listing
- Product Search
- Shopping Cart
- Checkout System
- Admin Dashboard
- Order Management
- Responsive Design

## Technologies Used
- PHP
- MySQL
- HTML5
- CSS3
- JavaScript

## Project Purpose
This project was developed for learning purposes and to showcase my web development skills. It is intended to demonstrate backend and frontend development concepts for my portfolio and resume.

## How to Run
1. Install XAMPP.
2. Copy the project folder into `htdocs`.
3. Start Apache and MySQL.
4. Import the database into phpMyAdmin.
5. Open the project in your browser using:
   ```
   http://localhost/your-project-folder
   ```
